# imgtech — сравнение чертежей и текстовых PDF

Сервис находит отличия между двумя версиями PDF-документа (чертежи из CAD и
текст) и показывает их рамками поверх страниц.

## Структура

- **`core/`** — движок векторного сравнения (каноничная версия + тесты).
  Сравнивает векторные примитивы страниц напрямую, без рендеринга в растр:
  устойчив к «шуму экспорта» и глобальному сдвигу страницы, отдаёт точные
  координаты отличий. Тесты: `python3 -m core.tests.run_tests`.
- **`api/`** — serverless-функция для Vercel (FastAPI + PyMuPDF):
  `POST /api/compare` принимает два PDF, возвращает JSON с рамками отличий
  графики и текста по каждой странице. `api/vector_compare.py` — копия
  `core/vector_compare.py` (функция должна быть самодостаточной).
- **`frontend/`** — React (Vite) интерфейс: загрузка двух PDF, рендер страниц
  через pdf.js бок о бок, отличия графики — красным, текста — оранжевым.
- **`img/`** — прежнее Flask-приложение (uWSGI, растровый пайплайн с
  PyTorch-автоэнкодером). Оставлено как референс до полного перехода.
- **`nginx/`, `cleaner/`** — обвязка прежнего деплоя через docker-compose.

## Локальный запуск

```bash
pip install -r requirements.txt uvicorn
uvicorn api.index:app --port 8000        # API
cd frontend && npm install && npm run dev # UI на :5173, /api проксируется на :8000
```

## Деплой на Vercel

Репозиторий готов к импорту как есть: `vercel.json` собирает фронт
(`frontend/dist`) и поднимает `api/index.py` как Python-функцию,
`/api/*` роутится на неё. Root Directory при импорте — корень репозитория.

Ограничения Vercel для теста: тело запроса ≤ ~4.5 МБ (оба PDF суммарно),
таймаут функции 60 с.
