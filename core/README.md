# core — движок векторного сравнения PDF

Первая версия ядра для сравнения чертежей на уровне векторных примитивов
(вместо рендеринга в растр и попиксельной разности).

## Идея

1. Вся векторная графика страницы (`page.get_drawings()`) сэмплируется в
   облако точек с фиксированным шагом — представление инвариантно к порядку
   путей, разбиению отрезков и способу аппроксимации кривых («шум экспорта»).
2. Глобальный сдвиг между страницами оценивается перебором по сетке
   заполненности и уточняется субпиксельно.
3. Точки каждой страницы ищутся в облаке другой с допуском `eps` —
   несопоставившиеся точки кластеризуются в прямоугольники отличий.
4. Если доля несопоставившихся точек аномально высокая (`unmatched_share`),
   представления несовместимы — вызывающий код откатывается на растровое
   сравнение.

## Использование

```python
import fitz
from core.vector_compare import compare_page_vectors

doc1, doc2 = fitz.open("a.pdf"), fitz.open("b.pdf")
result = compare_page_vectors(doc1[0], doc2[0])
result["boxes1"]  # (x0, y0, x1, y1) отличий на странице 1
result["boxes2"]  # то же для страницы 2
result["unmatched_share"]  # > 0.6 — нужен растровый fallback
```

## Тесты

Из корня репозитория:

```
python3 -m core.tests.run_tests
```

Синтетические «CAD-подобные» пары проверяют: устойчивость к другому
представлению той же геометрии, к глобальному сдвигу страницы, и поиск
реальных изменений без ложных срабатываний.
